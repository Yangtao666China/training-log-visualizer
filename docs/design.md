# TrainLens 的几个设计选择

## 为什么只读 CSV？

CSV 容易从训练循环、表格软件和各种实验工具导出。第一版限定列名与数值约定，减少“看起来生成成功，实际读取错误”的情况。CLI 接受引号包裹的 glob，并自行展开，因此 Windows 与 Unix 使用相同命令。

## 最优值与平滑分开

指数平滑 `s[t] = beta*s[t-1] + (1-beta)*x[t]` 会改变极值位置。它只用于观察趋势，不能替换真实记录来选择模型。因此排序、最佳轮次、JSON 导出全部使用原始值。图中指标切换也不会改变报告生成时指定的评价标准。

## 单文件与隐私

HTML 内嵌 CSS、JavaScript、SVG 曲线及日志数据，无在线字体、图表 CDN 或遥测请求。可以断网打开。分享报告等同于分享其中的全部日志，请在需要时先筛选输入文件。

## 防止文件名变成 HTML

用户提供的标题使用 HTML 转义；JSON 嵌入前转义小于号，防止文件名构造 `</script>` 提前结束数据块。浏览器端使用 `textContent` 设置实验名与表格，不拼接不受信任的 HTML。

## 为何不自动判定过拟合？

验证损失高于训练损失可能与样本差异、正则化、损失计算方式等有关。报告只展示最优轮次的差值，不把单次观察直接包装成诊断。应结合曲线、多次重复实验和数据划分检查。
